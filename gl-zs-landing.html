Частые вопросы

сначала самообслуживание
Как установить приоритет по заявке?Приоритет +

Выставьте обращение в АС Друг. Количество приоритетов для каждого ТБ ограничено; приоритет заранее согласуйте с руководителем.

  • От ТМ приоритет принимают только по согласованию директора МЦК и директора ЦООП.
  • Укажите причину срочности и срок, к которому нужно заключение.
Не покрывает кейс? Спросить базу ГЛ
Приоритет не выставляется — что ответить?Приоритет +

Ветка приоритета — только для установки приоритета по заявкам. Лимит приоритетов на ТБ ограничен.

Если запрос не про приоритет (например, осмотр) — направьте в нужный канал, а не в эту ветку.

Спросить базу ГЛ
Не согласен со стоимостью — что делать?Стоимость +

Нужно аргументированное мнение для пересмотра:

  • почему оценка занижена или завышена;
  • сопоставимые аналоги;
  • подтверждения (ДКП, рыночные предложения).

По предварительному мнению (ПМ) стоимость не пересматривают — нужна полноценная экспертиза.

Спросить базу ГЛ
После автооценки можно ли арбитраж?Автооценка +

Нет. Автооценка — продукт ММБ, Залоговая служба в процессе не участвует. Арбитраж после автооценки не проводят.

  • Отправьте заявку на ЗС заново как новый / последующий залог.
  • Экспертиза пройдёт сотрудником ЗС в полном объёме.
Спросить базу ГЛ
Почему КК «Комфорт»?Категория качества +

Типовые причины КК Комфорт:

  • нет чётких идентификационных признаков (например, шильдов) — часто сначала бланк, после устранения возможен комфорт;
  • специфика объекта (узкоспециализированное имущество);
  • только балансовый учёт без рыночной оценки / полного пакета.

Сверьте залоговое заключение с этими пунктами по вашему объекту.

Почему КК бланковое, а не комфорт?Категория качества +
  • нет нужных документов / осмотра / идентификации;
  • объекты на счёте 08 до перевода на 01;
  • не исполнены отлагательные условия сделки.

Нужны ВТИ или снятие рискаВТИ +

Что такое бессрочное СЗЗ?Сроки и ЭКД +

Бессрочное СЗЗ — сводное залоговое заключение в специальном режиме выпуска (часто роботом). Срок действия и мониторинг зависят от условий выпуска и актуальности материалов.

Спросить базу ГЛ
Срок действия СЗЗ, ЭКД, отчёты об оценкеСроки и ЭКД +
  • Последзалог: обычно до 12 месяцев с выпуска, осмотр не старше 12 месяцев, без негатива в мониторинге.
  • ЭКД ММБ: клиент / досье сделок / ID CRM / Заключения / Заключения по залогу.
  • Отчёт оценщика: порядок — приложение 8 Регламента 2222.
