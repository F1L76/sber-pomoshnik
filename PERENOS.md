# Перенос СберБизнес Помощник на другой ПК

Архив собран из репозитория **без** секретов (`.env`), `node_modules`, `python-deps` и локальной базы сделок (~ГБ).

## Mac (рекомендуется)

1. Распакуйте архив.
2. В терминале в папке проекта:
   ```bash
   cp .env.example .env
   # отредактируйте .env — вставьте ключи (GigaChat и др.), если нужны
   npm install
   npm start
   ```
3. Откройте http://localhost:8787/
4. Заметки со встречи: http://localhost:8787/meeting-notes  
   OCR через **macOS Vision** работает только на Mac.

Либо двойной щелчок по `start.command` в папке проекта.

## Windows / Linux

Те же шаги `npm install` → правки `.env` → `npm start`.  
OCR заметок на сервере (Vision) **недоступен** — на странице `/meeting-notes` сработает запасной Tesseract в браузере, либо вставляйте текст вручную.

## База сделок (опционально)

Локальный `data/deals/deals.sqlite` в архив не входит. На новом ПК при необходимости:
```bash
npm run deals:import
```
(нужны исходные данные/скрипты импорта — см. README и scripts).

## Не копируйте

- `.env` со старого ПК в открытый канал — лучше заново из `.env.example` и секретницы.
- `data/deals/*.sqlite*`, `.cache/`, `python-deps/` — ставятся/собираются на месте.
